# devver — быстрое заполнение отклика

После отправки формы расширение сообщает devver адрес и заголовок страницы.
Python API пытается найти вакансию в каталоге и создаёт отклик со статусом
«отправлен». Повторная отправка обновляет существующий отклик, а если вакансия
не найдена, расширение предлагает добавить её вручную.

Расширение для Zen Browser / Firefox. Оно универсально: запускается на текущей HTTP(S)-странице и ищет поля формы отклика по подписям, `name`, `id`, `placeholder` и `autocomplete`. ASTON — первый проверочный сайт.

Для Google Chrome используется отдельная Manifest V3-сборка из папки
`extension-chrome` или архива `jobs-dev-zen-extension-chrome.zip`.

## Установка в Chrome для проверки

1. Открой devver и зайди в аккаунт на `https://devver.ru`.
2. Открой `chrome://extensions`, включи **Developer mode**.
3. Нажми **Load unpacked** и выбери папку `extension-chrome` из этого проекта.
4. Открой страницу с формой отклика. Для первой проверки можно использовать вакансию ASTON на `career.astondevs.ru/vacancy/...`.
5. Нажми на иконку расширения и выбери **заполнить форму**. Для безопасной проверки откликов можно нажать **тест: отметить отклик (без отправки)** — форма на сайте не отправляется, а адрес текущей вакансии проверяется в каталоге devver.

После обновления расширения перезагрузи вкладку с вакансией, чтобы на странице загрузилась новая версия content script.

Расширение заполнит имя, фамилию, email, телефон, Telegram, сопроводительное письмо и прикрепит сохранённый файл выбранного резюме через безопасную передачу частями. На страницах вакансий с маршрутами вроде `/vacancy/500008230`, `/job/...` или `/position/...` оно дополнительно покажет подсказку с кнопками заполнения и тестовой отметки отклика. Перед отправкой обязательно проверь данные и самостоятельно нажми кнопку отправки на сайте.

Для резюме, импортированных из HH.ru, файл автоматически прикрепить нельзя, пока у devver нет самого файла; текстовые данные при этом могут быть подставлены.

Если в профиле у резюме написано «файл отсутствует», загрузи PDF или DOCX заново: старые записи могут содержать распознанные данные без самого бинарного файла.
