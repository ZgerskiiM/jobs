# jobs.dev — быстрое заполнение отклика

Расширение для Zen Browser / Firefox. Оно универсально: запускается на текущей HTTP(S)-странице и ищет поля формы отклика по подписям, `name`, `id`, `placeholder` и `autocomplete`. ASTON — первый проверочный сайт.

## Установка в Zen для проверки

1. Открой Zen и зайди в аккаунт на `https://jobs-dev.zgerskiim.chatgpt.site`.
2. Перейди в `about:debugging` → **This Zen** → **Load Temporary Add-on**.
3. Выбери файл `extension/manifest.json` из этого проекта.
4. Открой страницу с формой отклика. Для первой проверки можно использовать вакансию ASTON на `career.astondevs.ru/vacancy/...`.
5. Нажми на иконку расширения и выбери **заполнить форму**.

После обновления расширения перезагрузи вкладку с вакансией, чтобы на странице загрузилась новая версия content script.

Расширение заполнит имя, фамилию, email, телефон, Telegram, сопроводительное письмо и прикрепит сохранённый файл выбранного резюме через безопасную передачу частями. Перед отправкой обязательно проверь данные и самостоятельно нажми кнопку отправки на сайте.

Для резюме, импортированных из HH.ru, файл автоматически прикрепить нельзя, пока у jobs.dev нет самого файла; текстовые данные при этом могут быть подставлены.

Если в профиле у резюме написано «файл отсутствует», загрузи PDF или DOCX заново: старые записи могут содержать распознанные данные без самого бинарного файла.
